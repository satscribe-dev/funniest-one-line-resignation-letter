Entry for the [make.fun bounty](https://make.fun/bounty/u-deranalabs-the-funniest-one-line-resignation-letter-53c0d947): a program that writes the one-line resignation letter of a cron job — 140 characters at most — to `/output/entry.txt`.

Run it with Node 22:

```sh
node main.ts
```

It writes exactly one line (124 characters), deterministically: two runs produce byte-identical output.
